Personal rclone Drive Client

A private Google OAuth client that lets the open-source tool rclone, running on the owner's own computers, reach the owner's own Google Drive.

This is not a public service. There is nothing to sign up for and no hosted app. The client exists only so that its owner can use rclone with Google Drive without sharing rclone's default, rate-limited client ID with every other rclone user.

What it does

rclone is a free, open-source command-line program for managing files on cloud storage. When rclone is set up with this client, it asks Google for permission to read and manage the signed-in user's Google Drive so that it can:

  • list the files and folders in the user's Drive,
  • copy, sync, back up and download files between the user's computer and their Drive,
  • mount or stream the user's Drive files on the user's own devices.

Where your data goes

Everything runs locally. File contents and metadata travel directly between Google's servers and the computer running rclone. No server operated by the owner of this client ever receives, stores or sees Google user data. The full details are in the Privacy Policy.

Permissions requested

  • https://www.googleapis.com/auth/drive — see, edit, create and delete files in the user's Google Drive.
  • https://www.googleapis.com/auth/docs — see, edit, create and delete Google Docs-format files, so rclone can export and import them.
  • https://www.googleapis.com/auth/drive.metadata.readonly — read file names and details (metadata) without changing anything.
